# Contributing

Thank you very much for your interest in contributing to `qiskit_clifft_backend`! Based on the type of
contribution, it will fall into three categories:

1. Report a bug, feature request, or documentation issue:

    File an [issue][issues] describing what you encountered or what
    you want to see changed. The maintainer will evaluate the issues and triage
    them, scheduling them for a release. If you believe the issue needs priority
    attention comment on the issue to notify the team.

2. Share your work built upon `qiskit_clifft_backend`:

    We would love to hear more about your work! Please share with us on
    [GitHub
    Discussions](https://github.com/ACE07-Sev/qiskit_clifft_backend/discussions) or consider
    contributing to our [examples](/notebooks/)!

3. Implement a feature or bug-fix:

    Please file an [issue][issues] on the repository and express
    your interest in contributing to its implementation. The maintainer
    will respond on the issue to discuss how to best proceed with the
    suggestion. For more information regarding contributing to the code base,
    see also [DEVELOPING.md](./DEVELOPING.md).

[issues]: https://github.com/ACE07-Sev/qiskit_clifft_backend/issues
